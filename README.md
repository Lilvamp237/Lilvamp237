## 🚀 Key Projects

A mix of competition builds, research prototypes, and passion projects — full case studies with implementation details on my [portfolio](https://sumudu-ratnayake-portfolio.vercel.app/projects).

* **DengueSentinel:** A forecasting and optimisation platform predicting dengue transmission risk 2–4 weeks ahead and allocating vector-control teams within budget constraints, with role-based dashboards for public health, hospital, and regional stakeholders.
* **NourishLoop:** A closed-loop, human-in-the-loop platform for nutritious, affordable, low-waste school meal planning in Sri Lanka, retraining its own demand model from real consumption data.
* **Ithihaasa Guru:** A LangGraph-based AI tutor combining an OWL ontology with RAG over Grade 8–11 textbooks and a locally-run LLM (Ollama) to score and give Sinhala-medium feedback on open-ended history questions.
* **Autonomous Vehicle Swarms:** A SUMO/TraCI simulation studying how Social Value Orientation and Nash-style conflict resolution shape collective outcomes at urban intersections, with an inverse-reinforcement-learning module estimating agent behaviour.
* **Athena:** An AI-powered cognitive wellness and dementia-care platform with sentiment tracking, medication management, and caregiver collaboration. 🏆 *Best Use of Technology — Data Odyssey 2025*
* **CareSync:** A burnout and wellness management platform for healthcare teams with shift scheduling, habit tracking, and Supabase row-level security. 🏆 *1st Runner-Up — Code with WIE 2025*
* **Green AI:** A Vue 3 + Django platform visualising AI model emissions and cloud data-centre energy use to support lower-carbon decisions. 🏆 *Champion — Data Odyssey 2024*
* **Intelligent Bookstore Simulation:** An autonomous bookstore combining OWL/SWRL reasoning, Mesa multi-agent modelling, and a Neo4j graph database for transparent, explainable inventory decisions.
* **Agentic Hotel Guest Experience Optimizer:** A K-Means + Random Forest + agentic RAG pipeline generating context-aware, segment-specific guest communications for a hospitality use case.
* **eGOV — Smart Governance Platform:** A multi-portal e-Governance platform (Next.js monorepo, Supabase/PostgreSQL, Docker) spanning citizen, admin, and analytics apps.
* **E-Shuttle:** A full-stack university transportation system — a Flutter mobile app plus an admin web portal for real-time shuttle tracking, ticketing, and route management.
* **Audio Denoising System:** A U-Net-based deep learning model removing background noise from audio, with a cross-platform PyQt5 GUI for recording, playback, and export.
* **Telecom Churn Prediction with Genetic Algorithm:** An ML system predicting customer churn, using a Genetic Algorithm for feature selection and a Streamlit dashboard for model comparison.
* **Local Multilingual RAG Chatbot:** A localized hospital chatbot supporting English/Sinhala via Ollama and LangChain, built for 100% data privacy.
* **Market Analysis Platform:** An agent-based platform for real-time market analysis, using autonomous agents to simulate and predict market trends.
* **Pokémon Predictive Meta-Balance System:** An Isolation Forest + Random Forest tool flagging anomalous stat designs and predicting competitive viability across generations.

*(Plus several more — Smart Home Energy Tracker, Smart Study Companion, Localloop, Budget Buddy, Face Recognition Attendance, and others — see the full [project list](https://sumudu-ratnayake-portfolio.vercel.app/projects).)*
